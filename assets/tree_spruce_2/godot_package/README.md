# tree_spruce_2 (v2)

Дерево: ствол и ветки из модели + процедурные ветки, тёмная подложка кроны (CrownCore), 1245 листовых карточек (Leaves) с альфа-атласом 2x2.

- Треугольников: 5558 (ствол 468, подложка 2600, листья 2490).
- Сцена `tree_spruce_2.tscn`: скрипт `af_leaves_wind.gd` ставит на Leaves материал `leaves_wind.gdshader` (alpha scissor 0.5, ветер: UV2.x — сила, UV2.y — фаза, COLOR — оттенок карточки).
- Пути в .tscn относительные: папку пакета можно класть в любое место `res://`.
