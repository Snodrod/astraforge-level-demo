# tree_birch_3 (v2)

Дерево: ствол и ветки из модели + процедурные ветки, тёмная подложка кроны (CrownCore), 1500 листовых карточек (Leaves) с альфа-атласом 2x2.

- Треугольников: 5248 (ствол 1528, подложка 720, листья 3000).
- Сцена `tree_birch_3.tscn`: скрипт `af_leaves_wind.gd` ставит на Leaves материал `leaves_wind.gdshader` (alpha scissor 0.5, ветер: UV2.x — сила, UV2.y — фаза, COLOR — оттенок карточки).
- Пути в .tscn относительные: папку пакета можно класть в любое место `res://`.
