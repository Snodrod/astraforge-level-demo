# fern (v2)

Дерево: ствол и ветки из модели + процедурные ветки, тёмная подложка кроны (CrownCore), 3 листовых карточек (Leaves) с альфа-атласом 2x2.

- Треугольников: 24 (ствол 0, подложка 0, листья 24).
- Сцена `fern.tscn`: скрипт `af_leaves_wind.gd` ставит на Leaves материал `leaves_wind.gdshader` (alpha scissor 0.5, ветер: UV2.x — сила, UV2.y — фаза, COLOR — оттенок карточки).
- Пути в .tscn относительные: папку пакета можно класть в любое место `res://`.
